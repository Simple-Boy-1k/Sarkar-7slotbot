# 🤖 Telegram 7-Slot Admin Control Force Sub Bot

A Telegram Force Join Bot built with **Pyrogram** and **SQLite**, featuring a full-featured Admin Control Panel.

## 🌟 Features
- **1 to 7 Channel Slots:** Dynamic force subscription verification.
- **Set / Remove Media:** Support for Photo and Video banners on `/start`.
- **Set / Remove Voice Note:** Custom voice greeting on `/start`.
- **Custom Click Button:** Add/remove inline URL button.
- **Admin Management:** Add/remove secondary admins dynamically.
- **Broadcast & Stats:** Send messages to all users and view total user count.

## 🚀 Environment Variables
- `API_ID` - Telegram API ID from my.telegram.org
- `API_HASH` - Telegram API Hash from my.telegram.org
- `BOT_TOKEN` - Telegram Bot Token from @BotFather
- `OWNER_ID` - Owner's Telegram User ID
