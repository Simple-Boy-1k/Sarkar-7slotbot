# 🤖 Telegram 7-Slot Admin Control Force Sub Bot

A powerful Telegram Force Join Bot built with **Pyrogram** and **SQLite**, featuring a full-featured Admin Control Panel.

---

### 🚀 Deploy To Heroku

Neeche diye gaye button par click karke direct Heroku par deploy karein:

[![Deploy](https://www.herokucdn.com/deploy/button.svg)](https://heroku.com/deploy?template=https://github.com/Simple-Boy-1k/YOUR_REPOSITORY_NAME)

> ⚠️ **Note:** Upar diye gaye link me `YOUR_REPOSITORY_NAME` ko hata kar apne Telegram / GitHub repo ka real naam likh dein.

---

## 🌟 Features
- **1 to 7 Channel Slots:** Dynamic force subscription verification.
- **Set / Remove Media:** Support for Photo and Video banners on `/start`.
- **Set / Remove Voice Note:** Custom voice greeting on `/start`.
- **Custom Click Link:** Add/remove custom inline URL button.
- **Admin Management:** Add/remove secondary admins dynamically.
- **Broadcast & Stats:** Send broadcast messages to all users and check total user count.

## 🔑 Heroku Config Vars (Environment Variables)

Heroku deploy karte waqt yeh values fill karein:

| Variable | Description |
| :--- | :--- |
| `API_ID` | Telegram API ID ([my.telegram.org](https://my.telegram.org)) |
| `API_HASH` | Telegram API Hash ([my.telegram.org](https://my.telegram.org)) |
| `BOT_TOKEN` | Bot Token ([@BotFather](https://t.me/BotFather)) |
| `OWNER_ID` | Aapki Telegram Numeric User ID |
